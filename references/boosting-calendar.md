## How to Boost in Facebook Ads Manager

For each post below:
1. Go to **Meta Business Suite → Boost Post** on the published post
2. Set **Audience** as described (create saved audiences for reuse)
3. Set **Duration** to 5–7 days
4. Set **Budget** as listed
5. Select **Goal** as described
6. Run on **Facebook + Instagram** simultaneously

**Create these three saved audiences once and reuse:**

| Audience Name | Age | Location | Interests |

## Boost Performance — What to Watch

After each boost, check these three numbers in Meta Business Suite:

| Metric | What It Tells You | Good Benchmark (local, $7–$10 boost) |
|---|---|---|
| Reach | How many unique people saw it | 1,200–2,500 |
| Engagement rate | Likes + comments + shares ÷ reach | 3–6% |
| Link clicks (if applicable) | Traffic driven to website | 20–60 clicks |

If a boosted post significantly outperforms these benchmarks, note the topic and format — that is a signal to create more content in that category.

---

## Boosting Rules of Thumb

1. **Never boost a post that isn't performing organically.** If it has fewer than 5 organic likes after 24 hours, rewrite the caption before boosting.
2. **Always boost from the published post**, not from Ads Manager from scratch — boosted posts show social proof (likes, comments) which increases trust.
3. **Do not boost the same audience more than twice in the same month** — rotate between Homeowners Core, Business Owners, and Outdoor & Rural to avoid audience fatigue.
4. **Organic content (engagement questions, community posts, fishing reports) should never be boosted** — these perform best when they feel authentic and unsponsored.
5. **Review spend monthly** — if a category (business hooks, fleet coverage) is driving calls, increase the budget there. If a category is underperforming, swap it for a different post type.
